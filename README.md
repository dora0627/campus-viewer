# 成大校園 3D 檢視器

公開網頁:https://dora0627.github.io/campus-viewer/

由 `ncku-campus`(private)的 `tools/publish_viewer.py` 產生,請不要直接改這裡。

- 模型、貼圖由程式依規格畫出;不含 Google 截圖與國土測繪中心影像。
- `data.json` 的建築輪廓與道路衍生自 OpenStreetMap,© OpenStreetMap contributors,以 [ODbL](https://opendatacommons.org/licenses/odbl/) 授權提供。
- 研究用展示,非國立成功大學官方網站。
